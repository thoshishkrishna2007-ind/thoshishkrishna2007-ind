## 🎯 Overview

**GENESIS Platform** is a complete ecosystem for managing innovation and startup expos — from event creation through registration, navigation, and admin control.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📅 **Event Management** | Create & manage expo events end-to-end |
| 📝 **Registration System** | Seamless participant & exhibitor onboarding |
| 🎙️ **AI Voice Navigation** | Voice-guided event navigation |
| 📊 **Admin Dashboard** | Real-time analytics & control center |

## 🧠 Platform Flow

```
Create Event → Open Registration → Voice Navigation → Live Event → Analytics
```

## 🛠️ Technology Stack

- **Frontend**: React, Next.js, Tailwind
- **Backend**: Node.js, FastAPI
- **AI**: Voice Navigation models
- **Database**: Scalable cloud storage

## 🎤 AI Voice Navigation

Visitors navigate the expo hands-free with an AI assistant that understands natural language and guides them to booths, sessions, and stages.
